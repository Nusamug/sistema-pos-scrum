* **Como** usuario del sistema (Administrador, Mesero, Cajero, Cocinero),

### Criterios de Aceptación
* [ ] Formulario de inicio de sesión con usuario y contraseña[cite: 2].
* [ ] Redirección automática según el rol asignado[cite: 1].

## US-02: Configuración de Zonas y Mesas
* **Como** administrador,
* **Quiero** crear zonas y registrar mesas con su número identificador,
* **Para** estructurar la distribución del restaurante[cite: 1].

### Criterios de Aceptación
* [ ] Permite crear zonas (ej: Salón Principal, Terraza, Pets)[cite: 1].
* [ ] Permite registrar mesas asignadas a una zona[cite: 1].
* [ ] Estado inicial por defecto de toda mesa nueva: `Libre`[cite: 1].
* **Estimación:** 5 Puntos de Historia[cite: 1, 2].
